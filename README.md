# 🔥 GODZILLERS Crypto Tracker

**Dragon's Lair War Room Theme • Hidden Analytics • Active Signals Only**

A professional cryptocurrency trading signal dashboard with hidden analytical formulas and conditional display logic.

## 🚀 Features

- **Hidden Analytics**: All formulas (TOR, .onion, P_micro) are calculated internally and never exposed
- **Conditional Display**: Shows only active BUY/SELL signals, hides NEUTRAL altcoins
- **BTC Always Visible**: Bitcoin price and signal always displayed
- **State Persistence**: Previous values preserved between sessions
- **War Room Theme**: Deep black to blood red gradient with Orbitron/Rajdhani fonts

## 📋 Supported Coins

- **BTC** (Bitcoin) - Always visible
- **ETH** (Ethereum) - Conditional display
- **SUI, LINK, SOL, XRP, TAO, ENA, ADA, DOGE, BRETT** - Conditional display
